# 🪔 Chhath Digital Ghat (छठ महापर्व डिजिटल पोर्टल)

A comprehensive, state-of-the-art devotional, civic, and cultural web portal dedicated to **Chhath Mahaparv (छठ पूजा)**. Built with modern React and Vite, featuring an interactive devotional jukebox, a smart Puja Samagri & Prasad quantity calculator, real-time civic ghat monitoring, and cultural guides.

---

## 🌟 Key Features

1. **🌅 Cinematic Hero Dashboard**:
   - High-definition Chhath Ghat backdrop with sunrise Arghya aesthetics.
   - Live Arghya countdown timer, civic status ticker, and quick navigation.

2. **🎶 Devotional Jukebox (Music Player)**:
   - **Track #1**: *"छठी मईया (Chhathi Maiya)"* — Sung by **Vishal Mishra** from the 2026 film *The Vvaan*.
   - Iconic Chhath geets by Padma Bhushan **Sharda Sinha** (*"मारबो रे सुगवा"*, *"सोने के खड़ाउवा"*, *"हो दीनानाथ"*, *"केलवा के पात पर"*).
   - Classic hymns by **Pappu Mishra** and **Vindhyavasini Devi**.
   - Floating audio widget with spinning vinyl, equalizer waves, timeline scrubber, and expandable playlist.

3. **⚖️ Smart Puja Samagri & Prasad Calculator**:
   - Automatically calculates exact quantities (in **kg, grams, pieces, dozens, liters**) based on the number of Vratis, Dauras, and family members.
   - Covers 29+ essential items: Wheat flour, Jaggery, Cow Ghee, Arwa Rice, Daura, Sup, Diya, Sugarcane, Haldi, etc.
   - Interactive checkbox shopping checklist saved in `localStorage`.
   - One-click **WhatsApp Share** and Print/PDF export.

4. **📍 Ghats & Ponds Directory**:
   - 5-category organized directory: Major Ganga Ghats, Dedicated Ponds, Danger Zones (Red Flagged), Safety/Medical Booths, and Official Parking.
   - Live crowd level indicators (Low, Moderate, Peak), water depth status, and quick direction links.

5. **🏛️ Puja Administration & Emergency Helpline**:
   - District Administration contacts, Control Room hotlines, SDRF/NDRF rescue teams, Ambulance, and Police helpline numbers.
   - Official civic advisory and Clean Ganga guidelines.

6. **📸 Ghat Gallery & Cultural Guide**:
   - Visual showcase of Arghya ceremonies, Kharna preparations, and illuminated ghats.
   - 4-day Vedic timeline guide (Nahay-Khay, Kharna, Sandhya Arghya, Usha Arghya) with cultural and scientific significance.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Modern CSS3 (Variables, Flexbox/Grid, Glassmorphism, Responsive design)
- **Icons**: Lucide React
- **Audio Engine**: Custom HTML5 Web Audio Engine with background playlist support
- **Maps & Geolocation**: Leaflet & OpenStreetMap integration

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [Git](https://git-scm.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/chhath-digital-ghat.git

# Navigate into the project folder
cd chhath-digital-ghat

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
```

The optimized production output will be generated in the `dist/` directory, ready to deploy on **Vercel**, **Netlify**, or **GitHub Pages**.
